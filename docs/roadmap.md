# 后续扩展方向

> 基于当前 demo 可以继续深挖的方向。

## 通用

- 给根项目补充 npm scripts，减少手动命令
- 为工具增加参数校验和错误处理
- 增加文件搜索、HTTP 请求、Git 操作等更多工具
- 把 Agent 示例改成命令行可输入任意任务
- MCP Server 内存数据换成真实数据库或外部接口

## 对话记忆

- 增加数据库后端（Redis、MongoDB）
- 实现智能记忆压缩（关键信息提取、实体保留）
- 多用户会话隔离与权限控制

## Milvus 向量库

- 性能监控（查询延迟、内存占用）
- 增量更新：只向量化新增内容
- 对比 Pinecone、Weaviate、Chroma

## 电子书 RAG

- 支持 PDF、Markdown、TXT、DOCX
- 智能目录解析
- 构建多书籍知识图谱（角色关系、事件时间线）
- 引用精确到段落和页码
